# Paperclip 쉬운 한국어 패치

기존 Paperclip 서버를 유지하면서 메뉴부터 하위 설정·도움말까지 쉬운 한국어로 보여 주는 **비공식 로컬 표시 패치**입니다.

현재 번역 사전에는 **1,774개 항목**이 있습니다. [한국어 포크](https://github.com/yong076/paperclip-ko)와 [언어 플러그인](https://github.com/hinet/paperclip-lang)의 공개 번역 자료를 활용하고, 최신 화면 문구와 쉬운 설명을 보완했습니다. 저작권과 출처는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)를 확인하세요.

## 무엇이 한국어로 보이나요?

- 왼쪽 메뉴, 대시보드, 작업, 프로젝트, 에이전트, 반복 작업, 받은 편지함
- 조직·프로필·에이전트 설정, 권한 안내, 실행 기록 내보내기 설정, 시험 기능 설명
- 버튼, 상태, 입력 안내, 도움말, 오류 안내, 접근성 이름, 상대 시간
- 예: Routine → **반복 작업**, Heartbeat → **정기 실행**, Workspace → **작업 공간**, No cap → **추가 제한 없음**

이름과 작업 제목, 입력값, 비밀번호, 코드, 로그 원문은 보존합니다. API 키·환경 변수 이름·명령어처럼 작동에 필요한 값도 바꾸지 않습니다. 영어 원문이나 서비스가 새로 만든 안내가 사전에 없으면 원문이 남을 수 있습니다. **1,774개는 사전 항목 수이며 앱 전체 번역률을 뜻하지 않습니다.**

## 작동 방식

화면을 만드는 원본 JavaScript 파일은 수정하지 않습니다. 원본 HTML을 백업하고 로컬 번역 표시 스크립트 하나를 추가합니다. 이 스크립트는 화면이 그려질 때 정확히 일치하는 UI 문구와 일부 시간·상태 표현을 바꿉니다. 입력값이나 저장된 회사 데이터를 수정하지 않으며, 외부 번역 서버나 유료 API를 사용하지 않습니다.

브라우저 자동 번역이 다시 문구를 바꾸지 않도록 페이지를 `lang="ko"`, `translate="no"`로 표시합니다. React가 사용하는 텍스트 노드와 버튼 동작을 유지합니다.

## 적용하기

필요한 것은 Python 3.9 이상과 설치 폴더의 쓰기 권한입니다. 서버를 새로 설치하거나 멈출 필요는 없습니다.

1. 이 저장소를 받습니다.
2. 현재 Paperclip의 `@paperclipai/server/ui-dist` 폴더를 확인합니다. `ui-dist`는 **화면 파일 폴더**입니다. 회사 데이터 폴더를 지정하지 마세요.
3. 해당 폴더를 지정해 실행합니다.

```bash
python3 install.py --ui-dir "/path/to/node_modules/@paperclipai/server/ui-dist"
```

4. 브라우저를 새로고침합니다. 새로 열린 화면에도 한국어가 적용됩니다.

설치·재적용·복구는 데이터베이스, 로그인 방식, 권한, 예약 실행, 에이전트 실행 상태를 변경하지 않습니다. 경로가 잘못되면 적용을 중단합니다. 시스템 전체 폴더를 지우거나 광범위한 권한을 줄 필요는 없습니다.

## 되돌리기

```bash
python3 install.py --ui-dir "/path/to/node_modules/@paperclipai/server/ui-dist" --restore
```

처음 보관한 HTML로 복구합니다. 브라우저를 새로고침하면 됩니다. 백업은 `ui-dist/.paperclip-ko-easy-backup/index.html`에 있습니다. 여러 번 적용해도 번역 스크립트를 중복 추가하지 않습니다.

## 번역을 고치거나 늘리기

- `dictionary.json`: 실제 적용되는 전체 번역 사전. 영어 원문과 한국어를 짝지어 수정합니다.
- `easy-ko.json`: 이 패치에서 보완한 쉬운 한국어 자료입니다.
- `runtime.js`: 표시 처리 코드. 사용자 데이터 보존 규칙을 포함합니다.
- `install.py`: 백업·적용·복구 도구입니다.

사전을 바꾼 뒤 적용 명령을 다시 실행하고 브라우저를 새로고침하세요. 번역 내용에 따라 새 파일 이름을 만들어 브라우저에 예전 번역이 남지 않게 합니다.

## 확인한 범위와 한계

- 현재 적용·화면 확인 대상: 공식 npm 배포 **Paperclip 2026.1106.0**.
- 기본 메뉴, 프로젝트·작업·반복 작업·스킬·연결 서비스 화면, 일반·프로필·시험 설정, 에이전트 실행 환경·권한 설정, 새 작업 창을 실제 브라우저에서 확인했습니다.
- 노드 구조·클릭 이벤트 보존, 동적 화면 업데이트, 입력값·비밀번호·작업 제목·이름 보존을 자동 검사합니다.
- 적용·중복 적용·원본 복구와 잘못된 폴더 차단을 자동 검사합니다.
- 새 화면이 생기거나 원문이 바뀌면 번역 사전 보완이 필요합니다. 이 패치는 공식 국제화 기능이나 모든 영어 문구의 번역을 보장하지 않습니다.
- 원문 로그·코드·사용자 작성 본문은 원본 확인이 중요하므로 자동으로 바꾸지 않습니다.
- 프로그램 업데이트로 화면 폴더가 교체되면 패치도 다시 적용해야 합니다. 업데이트 전에 복구하고 새 버전 호환성을 확인하세요.

## 개발 검사

```bash
npm install --ignore-scripts
npm test
python3 test_installer.py
```

개발 검사에만 jsdom을 사용합니다. 실제 적용에는 npm 설치가 필요하지 않습니다. 설치 스크립트는 Python 표준 라이브러리만 사용하며 추가 서버를 실행하지 않습니다.

## 공개 범위

이 저장소에는 범용 번역 사전과 표시·설치·복구 코드 및 검사를 담습니다. 실제 회사 데이터, 로컬 컴퓨터 경로, 인증 정보, 개인 화면 캡처는 포함하지 않습니다.
